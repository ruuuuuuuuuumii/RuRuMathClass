# Ru's math class - 國中數學自主練習平台

專為國中學生設計的數學自主練習單元館別平台，支援單機離線執行，免註冊免帳號，具備本地 LocalStorage 進度存檔。

---

## 🎒 七年級主題規劃
* **整數運算館（整數的運算）**【籌備中】
  * 正負數四則運算、數線與絕對值挑戰。
* **質數館（因數與倍數 ‧ 100 以內的質數）**【🔥 開放練習中】
  * **🎈 質數神射手（射氣球挑戰）**：100 以內質數快速辨識，包含 1~30、1~60、1~100 三種難度，特意混入 51、57、87、91 等段考常見合數陷阱，點錯即時跳出質因數分解詳細解析。
  * **📜 25 質數收集館**：搭配「44223 - 22321」電話號碼口訣，分十位數分組點亮金幣徽章。
  * **🏆 榮譽大師證書**：全數收集 25 個質數後解鎖，蓋有 **【RuRuMin 合格認證】** 紅色印章，可填寫學生姓名/座號並直接截圖/列印繳交作業。
  * **💡 質數快篩秘笈**：4 步驟快篩原則（排 2、排 5、排 3 數字和、排 7 陷阱）。
* **一元一次方程館（一元一次方程式）**【籌備中】
* **直角坐標尋寶館（二元一次聯立與圖形）**【籌備中】

## 📘 八年級主題規劃
* **平方根館（平方根與畢氏定理 ‧ 完全平方數配對）**【🔥 新館開放！】
  * **🃏 完全平方數翻牌對決（卡牌記憶配對）**：
    * 翻開兩張卡牌進行配對，一邊是底數 $n$（例如 $17$），一邊是完全平方數 $n^2$（例如 $289$），訓練雙向反射神經。
    * 包含四種難度範圍：
      * **11~16 暖身區**（6 對共 12 張牌）
      * **11~20 核心區**（10 對共 20 張牌）
      * **11~25 精熟目標區**（15 對共 30 張牌，老師指定背誦目標！）
      * **11~32 王者挑戰區**（22 對共 44 張牌，高手進階）
  * **📜 完全平方數寶庫（11² ~ 25²）**：
    * 雙向速記秘笈（顛倒雙胞胎 $13^2=169$ 與 $14^2=196$、尾數 9 找 3 或 7、十位數夾擠法）。
  * **🏆 八年級完全平方數大師證書**：
    * 必須在翻牌對決中將 **11 ~ 25（共 15 組）全數成功配對解鎖**，才會正式頒發蓋有 **【RuRuMin 合格認證】** 的大師證書！
* **乘法公式連連看（乘法公式與多項式）**【籌備中】
* **因式分解拼圖大師（因式分解）**【籌備中】
* **一元二次方程式天秤（一元二次方程式）**【籌備中】
